PPT-Web 簡報工作站

把簡報拖進來，就能開始放映

檔案只在這台電腦上開啟，不會上傳到任何地方。

需要完整的動畫效果？

改用這台電腦上的 PowerPoint 放映：動畫和切換效果完全保留，手機一樣能遙控、看備忘稿。

準備檔案

  1. 在 PowerPoint 選「檔案 → 匯出 → 建立 PDF/XPS 文件」，存一份 PDF。
  2. 把 PDF 和原本的 PPTX 一起拖進來。PPTX 用來讀備忘稿。

備忘稿

←→ 換頁 F5 從頭放映 Shift+F5 從目前頁 B 黑幕 W 白幕 數字 + Enter 跳頁 Q 手機遙控

用 PowerPoint 放映

連接這台電腦上的 PowerPoint

  1. 下載橋接程式 PPT-Web-Bridge.cmd，雙擊執行並讓它開著。 第一次執行時 Windows 可能跳出警告，選「其他資訊 → 仍要執行」。
  2. 用 PowerPoint 打開你的簡報。
  3. 瀏覽器如果詢問是否允許這個網站存取這台裝置上的其他應用程式，請選「允許」。

橋接程式只接受這台電腦、而且只接受這個網站的連線；簡報檔案不會離開這台電腦。

備忘稿

←→ 上一步／下一步 F5 從頭放映 Shift+F5 從目前頁 Esc 結束放映 B 黑幕 Q 手機遙控

手機遙控

  1. 用手機相機掃描 QR Code
  2. 打開跳出的連結，就能翻頁、開黑幕、看備忘稿

這個視窗開著時，新的手機才能配對；配對過的手機斷線後會自動連回來。手機和電腦都要能上網，現場網路不穩時，讓電腦連手機熱點最穩。
