    用 PowerPoint 放映

    連接這台電腦上的 PowerPoint

    Safari 連不到這台電腦上的橋接程式，請改用 Chrome、Edge 或 Firefox 打開這個網站。

    1. 下載橋接程式 PPT-Web-Bridge.cmd，雙擊執行並讓它開著。 第一次執行時 Windows 可能跳出警告，選「其他資訊 → 仍要執行」。
    2. 下載 Mac 版橋接程式，解壓縮後打開「PPT-Web Bridge」並讓它開著。 第一次打開時 macOS 會說無法確認開發者：到「系統設定 → 隱私權與安全性」，在下方按「強制打開」。接著 macOS 問是否允許控制「Microsoft PowerPoint」時選「好」。
    3. 用 PowerPoint 打開你的簡報。
    4. 瀏覽器如果詢問是否允許這個網站存取這台裝置上的其他應用程式，請選「允許」。

    橋接程式只接受這台電腦、而且只接受這個網站的連線；簡報檔案不會離開這台電腦。

    手機遙控

    1. 用手機相機掃描 QR Code
    2. 打開跳出的連結，就能翻頁、開黑幕、看備忘稿

    這個視窗開著時，新的手機才能配對；配對過的手機斷線後會自動連回來。手機和電腦都要能上網，現場網路不穩時，讓電腦連手機熱點最穩。

    觀眾同步

    觀眾用手機掃描，就能跟著看目前這一頁，也能往回翻看已經講過的頁。

    觀眾看不到備忘稿，也看不到還沒講到的頁；只能看，不能翻你的簡報。這個連結會一直沿用，可以把 QR Code 放進投影片裡；想讓舊連結失效就按「換新連結」。
